# Mercedes Analytics Mobile (Flutter)

A cross-platform Flutter mobile client that connects to the existing Mercedes analytics backend API. This repository is the starting point for migrating the previous Valdi prototype into a production-ready native mobile app built with Flutter for both Android and iOS.

Goals
- Native-feeling cross-platform UI with Flutter (single codebase)
- Integrate securely with the Mercedes analytics backend (JWT cookie auth, cursor pagination)
- Provide feature parity with the prior prototype:
  - Authentication (login / logout / session management)
  - Dashboard with key analytics cards
  - Conversations list with pagination
  - Payments list with pagination and details
  - Embedded Metabase dashboards (webview or native embedding)
  - Production-grade CI, signing, and deployment

Repository layout (recommended)
- /android/                -> Android-specific resources and Gradle config (generated by Flutter)
- /ios/                    -> iOS-specific Xcode project (generated by Flutter)
- /lib/                    -> Flutter/Dart app source code
  - /lib/src/               -> app features and domain logic
  - /lib/ui/                -> UI components, widgets, themes
  - /lib/services/          -> API clients, auth, persistence
  - /lib/models/            -> Shared data models
  - /lib/navigation/        -> Routes and navigation
- /assets/                 -> App assets (images, fonts, icons)
- /docs/                   -> Documentation (this repo contains the docs below)

Quick start - development (Linux / macOS)
1. Install Flutter SDK: https://flutter.dev/docs/get-started/install
2. Install Android SDK components and set ANDROID_HOME (see SETUP.md)
3. Ensure you have Xcode and CocoaPods for iOS development (macOS only)
4. Run the app locally (connect to local backend via environment variables if needed):

```bash
# from repo root
flutter pub get
flutter run -d emulator-5554   # Android emulator name may vary
cd app
flutter pub get
flutter run -d emulator-5554   # Android emulator name may vary

Quick tips for fish shell (Linux):

Backend connection
- This app uses the existing Mercedes analytics backend API (see docs/API_INTEGRATION.md).
- The backend expects session authentication (JWT cookies) — the README and API docs cover the best approach, secure storage, and cookie handling for Dart/Flutter.

CI & Deploy
- Use a CI workflow to run flutter analyze, flutter test, and produce builds for Android and iOS.
- For Android, produce an App Bundle (AAB) for Play Store.
- For iOS, build signed artifacts for App Store Connect.
- See DEPLOYMENT.md for example GitHub Actions/Bitrise/CircleCI templates.
